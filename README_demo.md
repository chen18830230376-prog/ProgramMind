# ProgramMind · 面向高校计算机学科的 AI-Native 教学科研垂类大模型平台

> 国家级软件竞赛演示项目 · 一期 MVP：仅面向计算机学科（Python 程序设计 / 数据结构 / 计算机网络），覆盖教师、学生两类用户。

---

## 一、项目简介

ProgramMind 不是普通聊天机器人，也不是简单知识库，而是**任务优先（Task First）、知识可信（Knowledge First）、人机协同（Human-in-the-loop）、长期记忆（Long-term Memory）、AI 原生（AI-Native）** 的学科教学科研垂类大模型平台。

它要解决高校计算机教学中的三大痛点：

1. **学科知识资源分散**：教材、PPT、实验、习题彼此割裂，缺少统一知识网络 → ProgramMind 用「知识图谱 + 知识来源追溯」把资源织成网。
2. **教师备课命题重复劳动多**：教案、PPT、命题高度重复 → AI 教案生成 / PPT 大纲 / 智能命题，教师审核修改后发布（AI 不替代人）。
3. **只看考试结果、缺过程记录**：传统平台只记录分数 → ProgramMind 记录每一次学习、实验、提问、辅导的足迹，生成「全过程成长画像」。

## 二、核心创新点（五大产品原则，代码 / 界面 / 文档多处体现）

| 原则 | 体现 |
|------|------|
| **任务驱动 Task-driven** | 工作台即「任务中心」而非菜单首页；教师看到待备课/待批改/学情预警，学生看到今日计划/待办/AI 建议 |
| **知识可信 Knowledge First** | AI 回答均带「知识来源」标签，可追溯到教材/课件/实验指导；知识图谱可视化先修-后继关系 |
| **人机协同 Human-in-the-loop** | AI 生成教案/命题/报告后由教师/学生二次编辑发布，AI 辅助而非替代 |
| **长期记忆 Long-term Memory** | 学习记录、历史 AI 对话、收藏、成长轨迹全程留存，跨会话可回溯 |
| **AI 原生 AI-Native** | AI 能力渗透每个业务模块（学习辅导、实验调试、命题、总结、工作流），而非孤立聊天页 |

## 三、技术栈

**后端**
- Python 3 + Flask（轻量 Web 框架）
- **SQLite 数据库（零外部服务、文件即库）**：用户账号（`users` 表）与选课关系（`enrollments` 表）真实落库，支持**注册新账号**、**新学生选课**；课程/作业/知识点等演示业务数据仍用内存字典模拟，兼顾“真实可交互”与“一键演示不脏数据”
- 会话登录鉴权（`session` 保存登录态与用户身份，刷新不丢登录）
- 路由绑定：注册 / 登录 / 权限隔离 / flash 消息 / 各业务模块数据 API / 选课 API

**前端**
- Vue 3（组合式 API）+ Vue Router（独立 URL 路由）
- Element Plus + Tailwind CSS（大赛级现代 UI，深蓝 `#165DFF` + 浅灰，简约科技风）
- ECharts（知识图谱 / 学情柱状图 / 掌握度热力图 / 能力雷达图）
- 响应式布局、流畅过渡与卡片悬浮动效、首屏加载动画
- 浅色 / 暗黑双主题切换（持久化）
- 课程封面使用在线 CDN（picsum / pravatar）；**课程教材封面为本地 SVG**（`frontend/textbooks/*.svg`，离线可用、品牌色一致），在「学习资料 / 课程卡片 / 课程广场 / 教师课程」均可点击放大预览
- **所有 AI 功能均为前端模拟**（仿真大模型返回 + 打字机流式效果），无需真实 API 即可演示

## 五、运行步骤（一键演示）

> 前置：已安装 Python 3.10+。

```bash
# 1. 进入后端目录
cd programmind/backend

# 2. 安装依赖（仅 Flask，极简）
pip install -r requirements.txt

# 3. 启动服务
python app.py
```

启动后浏览器访问：**http://127.0.0.1:5000**

无需任何数据库初始化、无需前端构建（前端由 Flask 直接托管）。
首次启动会自动生成 `backend/programmind.db`（SQLite 文件），并播种演示账号与选课关系；
**支持在登录页注册新账号**，注册时选择专业即可自动匹配课程：

- 注册表单提供「专业」下拉（来自 `GET /api/courses/majors`），学生必选；
- 注册成功后会**自动加入该专业核心课程**（如选「软件工程」自动加入《Python 程序设计》《数据结构》），其余相关专业拓展课作为「为你推荐」展示；
- 新学生登录即能在「我的课程」看到已匹配课程，并可去「课程广场」一键选修推荐课，立即享受作业 / 测验 / 资料等学习资源；
- 选课关系真实落库（SQLite `enrollments` 表），教师端学生名单随选课实时联动。

> 专业 → 课程映射集中在 `backend/mock_data.py` 的 `MAJOR_COURSES`（core=核心课自动加入，recommend=推荐课），便于答辩讲解与后续扩展。

> **路径提示（易踩坑）**：项目根目录是 `programmind`，后端在其下的 `programmind/backend`。
> 若你当前位置是 `programmind` 的**上一级**（例如 `C:\Users\22131\Desktop\6666666`），
> 请先 `cd programmind\backend` 再执行 `pip` / `python`，否则会报
> 「找不到路径 / 找不到 requirements.txt / 找不到 app.py」。
>
> 也可以直接**双击** `programmind` 同级目录下的 **`run-demo.bat`** 一键启动（脚本会自动进入正确目录、装依赖、起服务）。

**演示账号（密码与账号一致）：**
| 身份 | 账号 | 密码 |
|------|------|------|
| 教师 | `teacher01` / `teacher02` | 同账号 |
| 学生 | `student01` ~ `student04` | 同账号 |

> 登录页提供「一键填充演示账号」按钮，方便评委快速体验。
> **也可点击「立即注册」创建新账号**：默认角色为学生（亦可注册教师），注册成功即自动登录；
> 新学生进入「学习模块 → 我的课程 → 课程广场·选课」即可加入课程并学习，全流程真实写入 SQLite 数据库。

## 六、竞赛演示说明（建议走查路线）

**教师视角（teacher01 登录）：**
1. 工作台：查看今日课表、待备课、AI 教案提醒、待批改、学情预警、AI 建议卡。
2. 教学模块 → 知识网络：拖拽/缩放课程知识图谱，实线为「先修」、虚线为「相关」。
3. 教学模块 → 教案生成：选课程章节，点「AI 生成教案」，观察打字机流式生成，可编辑保存。
4. 教学模块 → AI 智能命题：勾选知识点+难度，生成带知识来源的题目。
5. 教学模块 → 学情分析：ECharts 分组柱状图（各学生 + 班级平均），定位薄弱点。
6. AI 助手 → Agent 工作流：运行「教材分析→教案生成→PPT生成→作业设计」完整流程。
7. 成长模块：知识掌握热力地图、理论/实践雷达图、成长轨迹时间线、AI 成长报告。

**学生视角（student01 登录）：**
1. 工作台：今日计划、待办、AI 学习建议、成长趋势图、学习导航入口。
2. 学习模块 → AI 学习辅导：提问（如「装饰器有什么用」），AI 带知识来源标签流式回答（模拟 RAG）。
3. 学习模块 → 课程实验：查看教师发布的实验、提交实验报告、查看批改结果。
4. 学习模块 → 测验：答题后查看知识掌握分析。
5. 成长模块：查看自己的全过程学习画像与 AI 建议。
6. 个人中心：编辑资料、查看历史 AI 对话、收藏、消息、明暗主题切换。

**权限隔离演示：** 用学生账号访问 `/teach/...` 会自动跳回工作台；教师看不到学生专属学习模块——体现「权限隔离」。

## 八、合规与说明

- 本项目**刻意不接入数据库**，全部业务数据以内存字典模拟，便于竞赛现场反复演示、避免脏数据。
- 所有 AI 回答均为**前端模拟输出**，不含真实大模型调用；代码拿到手直接运行即可完整演示。
- 图片均使用可访问的在线 CDN（picsum.photos / pravatar.cc），运行需联网加载图片与 CDN 依赖。
- 工作台为「任务中心」首页，成长模块为核心创新亮点，AI 能力已渗透至各业务模块（AI-Native）。

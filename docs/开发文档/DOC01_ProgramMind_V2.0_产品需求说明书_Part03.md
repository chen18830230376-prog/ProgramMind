# ProgramMind V2.0 产品需求说明书（PRD）

# Part 03 —— 第八章 Student Center（学习中心）页面规格

> 本章节定义 Student Center 全部页面规格、交互流程、页面状态、按钮行为、权限说明，是学生端 Vue 页面开发唯一产品标准。

---

# 第八章 Student Center 页面规格（16 页面）

Student Center 是 ProgramMind 的学生学习中心，围绕 **课程学习 → AI辅导 → 作业实验 → 测验评价 → 成长反馈** 构建完整学习闭环。

---

## 8.1 Student Center 页面地图

```text
Student Center
│
├── S1 工作台
├── S2 我的课程
├── S3 今日学习
├── S4 学习资料
├── S5 AI 学习辅导
├── S6 AI 代码调试
├── S7 AI 复习规划
├── S8 作业中心
├── S9 作业详情
├── S10 实验中心
├── S11 实验详情
├── S12 测验中心
├── S13 在线测验
├── S14 导入题库
├── S15 学习记录
└── S16 通知中心（Drawer）
```

Student Center 共 **16 个页面**。

# 页面 S1 —— 学生工作台（Learning Workspace）

## 页面定位

学生每日进入 ProgramMind 的首页。

目标：

> 今天学什么、有哪些任务、当前学习状态、AI 给我什么建议。

路由：

```text
/workspace
```

---

## 页面布局

```text
Header
│
├── 欢迎卡片
├── 今日学习目标
│
课程概览
│
今日待办
│
成长概览
│
AI 今日建议
│
最近通知
```

---

## 模块一：欢迎卡片

展示内容：

| 字段      | 来源              |
| ------- | --------------- |
| 学生姓名    | 当前登录用户          |
| 专业      | User Profile    |
| 年级      | User Profile    |
| 今日日期    | 系统时间            |
| 今日学习时长  | Growth Center   |
| 今日完成任务数 | Learning Record |

按钮：

- 开始今日学习
- AI 学习辅导

---

## 模块二：今日学习目标

AI 根据课程生成目标。

展示：

| 信息     | 示例         |
| ------ | ---------- |
| 今日课程   | Python程序设计 |
| 推荐章节   | 第四章 函数     |
| 推荐学习时长 | 90分钟       |
| 推荐练习   | 递归练习题      |

支持：

- 一键开始学习。
- 跳转课程章节。

---

## 模块三：课程概览

展示所有已选课程。

课程卡片字段：

| 字段     |
| ------ |
| 封面     |
| 名称     |
| 教师     |
| 学习进度   |
| 下一章节   |
| 最近学习时间 |

支持：

- 搜索课程。
- 收藏课程。
- 查看课程详情。

---

## 模块四：今日待办

来源：

- 作业。
- 实验。
- 测验。
- AI 推荐学习任务。

展示：

| 类型         | 图标  |
| ---------- | --- |
| Homework   | 📝  |
| Quiz       | 📚  |
| Experiment | 🧪  |
| AI Tutor   | 🤖  |

支持一键进入。

---

## 模块五：成长概览

展示成长中心摘要。

内容：

- 今日学习时长。
- 本周连续学习。
- 当前成长等级。
- 掌握度平均值。

图表：

- 学习趋势折线图。
- 本周热力图。

点击进入 Growth Center。

---

## 模块六：AI 今日建议

AI 输出内容：

```text
今天建议学习：

Python函数递归

原因：

递归知识掌握度 56%。

建议：

完成实验2与递归测验。
```

按钮：

- AI Tutor
- AI Review

| 状态      | UI                 |
| ------- | ------------------ |
| Loading | Skeleton Dashboard |
| Empty   | 暂无课程               |
| Error   | Retry Button       |

## Student Center 页面开发规范

每个 Student 页面必须实现：

### 页面状态

| 状态               | 必须实现 |
| ---------------- | ---- |
| Loading Skeleton | ✅    |
| Empty 页面         | ✅    |
| Error Retry      | ✅    |
| Success          | ✅    |

### 页面权限

| 权限      | 描述               |
| ------- | ---------------- |
| Student | 可访问全部 Student 页面 |
| Teacher | 禁止访问 Student 页面  |
| 未登录     | 自动跳转 Login       |

### 页面数据来源

Student 页面所有数据来源于：

- Course Center
- Homework Service
- Experiment Service
- Quiz Service
- AI Service
- Growth Service

禁止直接读取数据库。
